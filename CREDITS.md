# Tecnologias e créditos / Technologies and credits

[Português](README.md) · [English](README.en.md)

## Português

O projeto de referência utiliza React, TypeScript, Vite, Tailwind CSS, Recharts, React Router, TanStack Query, React Hook Form, Zod, Python, FastAPI, Pydantic, SQLAlchemy, Alembic e SQLite. As ferramentas de validação citadas incluem pytest, httpx, Vitest, Testing Library, Playwright, Ruff e ESLint.

Os nomes identificam tecnologias utilizadas; não representam patrocínio, endosso ou reivindicação de titularidade sobre esses componentes. Os componentes de terceiros permanecem sujeitos às respectivas licenças e avisos. Esta apresentação documental não redistribui suas implementações.

The reference project uses React, TypeScript, Vite, Tailwind CSS, Recharts, React Router, TanStack Query, React Hook Form, Zod, Python, FastAPI, Pydantic, SQLAlchemy, Alembic and SQLite. The validation tools mentioned include pytest, httpx, Vitest, Testing Library, Playwright, Ruff and ESLint.
