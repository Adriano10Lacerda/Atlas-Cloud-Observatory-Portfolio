# Limitações / Limitations

[Português](../README.md) · [English](../README.en.md)

## Português

**V1 é um laboratório local com dados sintéticos e não está homologada para produção.**

- Não realiza monitoramento real nem coleta dados do computador ou de servidores remotos.
- Azure Monitor, coleta real e Lab Healing não estão implementados.
- Recuperações são simulações; não reiniciam serviços, removem arquivos ou executam comandos reais.
- Disponibilidade representa amostras sintéticas saudáveis retidas, não uptime real ou SLA.
- Causas prováveis são heurísticas, não diagnósticos confirmados.
- A configuração local com SQLite não demonstra funcionamento distribuído ou PostgreSQL homologado.
- Auditoria local não é armazenamento imutável.
- Testes históricos não substituem pentest, carga prolongada, avaliação de acessibilidade ou homologação independente.
- Não há alegação de MFA, multi-tenancy, gestão corporativa de identidades ou certificação de segurança.

Qualquer evolução operacional exigiria escopo, permissões, manutenção, controles e validação próprios. Este portfólio não oferece nem promete essa evolução como funcionalidade existente.

## English

**V1 is a local laboratory using synthetic data and has not been approved for production use.**

- It performs no real monitoring and collects no data from the computer or remote servers.
- Azure Monitor, real collection and Lab Healing are not implemented.
- Recovery is simulated; it does not restart services, remove files or execute real commands.
- Availability represents retained healthy synthetic samples, not real uptime or an SLA.
- Probable causes are heuristics, not confirmed diagnoses.
- The local SQLite setup does not demonstrate distributed operation or a validated PostgreSQL deployment.
- Local audit records are not immutable storage.
- Historical tests do not replace penetration testing, sustained load testing, accessibility evaluation or independent approval.
- No claim is made of MFA, multi-tenancy, enterprise identity management or security certification.

Any operational evolution would require its own scope, permissions, maintenance, controls and validation. This portfolio neither offers nor presents that evolution as an existing feature.
